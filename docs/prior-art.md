# Prior art and reuse decisions

Research snapshot, November 20, 2026. These are design and dependency decisions. Installation tests, measured savings and compatibility claims belong in the release evidence.

## What the video demonstrates

AI LABS links Tamara Tran’s public compactor in the video description, describes adapting it for Vercel AI Gateway, and directs viewers to AI LABS Pro for its skills and hooks. The other six demonstrations are behavioral references. The description supplies no separate public source or redistribution license for them. Its “Docs Checker” compares documented access rules against tests. General documentation drift detection is a separate proposed feature. [Video and creator’s description](https://www.youtube.com/watch?v=2nc_QMuNp18)

| Video chapter | Decision for this plugin |
|---|---|
| Compaction, 3:11 | Evaluate the public compaction library in the continuity release. Preserve native fallback and an exact recovery path. |
| Docs checker, 4:57 | Implement criterion-to-assertion matching in v1. Distinguish a likely test from evidence that the relevant assertion executed. |
| Skill picker, 5:49 | Route over an eligible inventory supplied for the active host. Send minimal metadata and allow abstention. |
| File search, 7:48 | Retrieve locally first. Rerank bounded excerpts and return verifiable paths and lines. |
| Code review, 9:05 | Use ranking for triage. The reviewer checks actual hunks, callers and consequences before confirming a finding. |
| Browser testing, 9:57 | Select a repo-owned test flow and ask the authorized runner to execute it. Store the assertion result and trace. |
| Rule enforcement, 11:15 | Parse explicit rules locally at a supported interception point. Jev may flag ambiguous prose. A confidence threshold cannot grant permission or establish a hard violation. |

## Integration and maintenance

The request path runs from the host to the local feature engine. The engine filters candidates by workspace and capability, then asks the selected provider a bounded question only when a local answer is insufficient. A normalized response selects from existing candidate IDs. The host owns execution and the local evidence records what ran. Later features can share these interfaces without introducing new credentials or billing paths.

The direct SDK was listed as `@typesafe-ai/sdk` 0.7.0 (MIT), OpenRouter’s as `@openrouter/sdk` 1.5.125 (Apache-2.0), and Vercel’s as `ai` 7.0.178 (Apache-2.0) at inspection. These were research references. Adding one later requires pinning the evaluated version, checking its actual license and dependencies, and ensuring its retry behavior respects reservations.
