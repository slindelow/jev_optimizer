# Jev provider adapters and spend controls · V1

**Input.** Selected connection, supported model ID, question version, approved state and named typed questions. Across providers V1 requires textual choice, yes/no probability and rubric score. Declare support for images and bounding boxes separately by model, route and tested adapter version. Route an unsupported capability back to the caller before sending data.

**Output.** Return candidate IDs or normalized scores/probabilities appropriate to the question, response model, usage, currency and billed amount when available, plus latency. Preserve confidence separately when supplied. Missing cost or confidence is unknown. Pin the host-facing schema with recorded, sanitized fixtures for each adapter. A network error, malformed result, or explicit abstention has a distinct status.

**Budget algorithm.** Use a user-confirmed monthly USD cap per connection shared across both hosts, plus optional tighter workspace limits. Reserve a conservative worst-case charge for the full serialized request in a transaction before sending. Use a versioned rate and a documented conservative token bound. Block paid dispatch when a safe bound is unavailable. On success settle actual usage or keep an explicitly estimated charge. On ambiguous delivery retain the reservation until reconciled or the user resolves it. A crash must preserve outstanding reservations. No automatic paid retry after ambiguous dispatch. Cancelling before send releases the reservation. This cap applies to plugin traffic and cannot control unrelated use of the account.

**Acceptance.** Replay each adapter against valid, malformed, rate-limited, timed-out and unsupported responses. Test concurrency across two processes, a rate change, invalid model alias, insufficient funds and a crash after dispatch. A provider failure must send zero requests to the other two. Confirm normalization by asking the same synthetic question on each live route with a predeclared cap. Do not demand identical stochastic choices across models.
